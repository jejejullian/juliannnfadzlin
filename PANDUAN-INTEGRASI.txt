====================================================================
BAGIAN 1: PERSIAPAN SUPABASE (Lakukan Ini Dulu!)
====================================================================

STEP 1.1 — Buat Project di Supabase
-------------------------------------
1. Buka https://supabase.com dan login
2. Klik "New project"
3. Isi nama project (contoh: "jeje-portfolio")
4. Set password database — SIMPAN password ini!
5. Pilih region terdekat (Singapore untuk Indonesia)
6. Tunggu project selesai dibuat (~1 menit)


STEP 1.2 — Ambil DATABASE_URL & DIRECT_URL
---------------------------------------------
Lokasi: Supabase Dashboard → Project Settings → Database → Connection String

  TAB "Session" (atau "Node.js"):
    → Copy → tempel ke DATABASE_URL di /backend/.env

  TAB "Transaction":
    → Copy → tempel ke DIRECT_URL di /backend/.env

  FORMAT URL:
  postgresql://postgres.[ref]:[PASSWORD]@aws-0-[region].pooler.supabase.com:[port]/postgres
  
  ⚠️ Ganti [PASSWORD] dengan password database Anda dari STEP 1.1


STEP 1.3 — Ambil SUPABASE_URL & SUPABASE_SERVICE_ROLE_KEY
-----------------------------------------------------------
Lokasi: Supabase Dashboard → Project Settings → API

  "Project URL":
    → Copy → tempel ke SUPABASE_URL di /backend/.env
    → Format: https://xxxxxxxxxxxxxx.supabase.co

  "service_role" (di bawah Project API Keys, klik "Reveal"):
    → Copy → tempel ke SUPABASE_SERVICE_ROLE_KEY di /backend/.env
    ⚠️ SANGAT RAHASIA — jangan pernah commit ke GitHub!


STEP 1.4 — Buat Storage Bucket untuk Gambar
--------------------------------------------
Lokasi: Supabase Dashboard → Storage → New Bucket

  Nama bucket : project-images
  Tipe        : ✅ Public (centang "Public bucket")
  → Klik Save

  ⚠️ Nama HARUS "project-images" (persis sama, huruf kecil, ada strip)
     Jika ingin nama lain, ubah juga di:
     /backend/middlewares/uploadMiddleware.js baris:
       const BUCKET_NAME = "project-images";  ← ganti di sini

====================================================================
BAGIAN 3: JALANKAN BACKEND (Di Terminal /backend)
====================================================================

Buka terminal, arahkan ke folder /backend:

  cd "d:\project with react js\jeje-portofolio\backend"

Lalu jalankan berurutan:

  STEP 3.1 — Install semua library:
    npm install

  STEP 3.2 — Buat tabel di Supabase otomatis dari schema:
    npx prisma db push

    Jika berhasil, terminal akan tampil:
    "Your database is now in sync with your Prisma schema."
    
    Untuk verifikasi, cek di Supabase → Table Editor
    → Harus ada tabel "Project" dengan kolom:
       id, title, description, tech_stack, image_url,
       live_link, github_link, createdAt, updatedAt

  STEP 3.3 — Jalankan server backend:
    node server.js
    
    Atau mode development (auto-restart saat file berubah):
    npm run dev

    Jika berhasil:
    ✅ Server berjalan di http://localhost:5000

  STEP 3.4 — Test backend berjalan:
    Buka browser → http://localhost:5000
    Harus tampil:
    {"status":"OK","message":"Portfolio Backend API is running 🚀"}


====================================================================
BAGIAN 4: JALANKAN ADMIN UI (Di Terminal /backend/admin-ui)
====================================================================

Buka terminal BARU, arahkan ke folder admin-ui:

  cd "d:\project with react js\jeje-portofolio\backend\admin-ui"

  STEP 4.1 — Pastikan .env sudah benar:
    File: /backend/admin-ui/.env
    Isi: VITE_API_URL=http://localhost:5000

  STEP 4.2 — Jalankan admin UI:
    npm run dev

    Admin panel tersedia di: http://localhost:5174 (atau port lain)

  STEP 4.3 — Login ke Admin Panel:
    - Buka http://localhost:5174
    - Masukkan ADMIN_PASSWORD (yang ada di /backend/.env)
    - Anda akan masuk ke Dashboard

  STEP 4.4 — Coba tambah project:
    - Klik "Tambah Project"
    - Isi semua field (Judul, Deskripsi, Tech Stack)
    - Upload gambar (maks 5MB)
    - Klik "Tambah Project"
    
    Jika berhasil:
    ✅ Toast "Project berhasil ditambahkan! 🎉" muncul
    ✅ Project muncul di tabel Dashboard
    ✅ Gambar tersimpan di Supabase Storage → Bucket "project-images"
    ✅ Data tersimpan di Supabase Database → Tabel "Project"

====================================================================
BAGIAN 6: DEPLOY KE LIVE HOSTING
====================================================================

STRUKTUR DEPLOY:
  Backend + Admin UI → Railway / Render (gratis tier tersedia)
  Frontend Portfolio → Vercel (gratis, sangat mudah)


--- DEPLOY BACKEND KE RAILWAY ---

  1. Push kode backend ke GitHub (pastikan .env masuk .gitignore!)
  2. Buka https://railway.app → New Project → Deploy from GitHub
  3. Pilih repo → Pilih folder /backend sebagai root
  4. Di Railway → Environment Variables, isi semua variable dari .env:
       DATABASE_URL = ...
       DIRECT_URL = ...
       SUPABASE_URL = ...
       SUPABASE_SERVICE_ROLE_KEY = ...
       JWT_SECRET = ...
       ADMIN_PASSWORD = ...
       PORT = 5000
       FRONTEND_URL = https://your-portfolio.vercel.app
  5. Railway akan otomatis run "npm start" → jalankan server.js
  6. Salin URL Railway Anda (contoh: https://jeje-backend.up.railway.app)


--- DEPLOY ADMIN UI KE RAILWAY/VERCEL ---

  1. Masuk ke folder /backend/admin-ui
  2. Ubah .env: VITE_API_URL=https://jeje-backend.up.railway.app
  3. Build: npm run build
  4. Deploy folder "dist" ke Vercel atau Railway
  5. Di Vercel → Environment Variables:
       VITE_API_URL = https://jeje-backend.up.railway.app


--- DEPLOY FRONTEND KE VERCEL ---

  1. Ubah /frontend/.env:
       VITE_API_URL=https://jeje-backend.up.railway.app
  2. Push frontend ke GitHub
  3. Buka https://vercel.com → Import Project → Pilih repo frontend
  4. Di Vercel → Environment Variables:
       VITE_API_URL = https://jeje-backend.up.railway.app
  5. Deploy!
  6. Salin URL Vercel → Update FRONTEND_URL di Railway backend

  ⚠️ PENTING SETELAH DEPLOY:
     Update FRONTEND_URL di backend environment variable Railway
     ke URL Vercel Anda, agar CORS tidak memblokir request!
