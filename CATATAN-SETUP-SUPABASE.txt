⚠️ SATU LANGKAH YANG HARUS JULIAN LAKUKAN SENDIRI (< 2 menit):
====================================================================

Kenapa tidak bisa dilakukan AI?
  → Supabase menyembunyikan/memotong service_role key di UI untuk
    keamanan. AI tidak bisa copy key yang ter-masking di browser.

LANGKAH-NYA (sangat mudah):

  1. Buka link ini:
     https://supabase.com/dashboard/project/trqmqclztcmtkkkaxzot/settings/api-keys

  2. Scroll ke bawah → cari section "Legacy anon, service_role API keys"
     (klik tab tersebut jika belum aktif)

  3. Di baris "service_role" → klik tombol "Reveal"

  4. Klik tombol "Copy" di sebelah kanan key tersebut

  5. Buka file:  backend/.env

  6. Ganti tulisan ini:
        SUPABASE_SERVICE_ROLE_KEY="COPY_DARI_SUPABASE_LEGACY_API_KEYS"
     
     Menjadi (contoh format):
        SUPABASE_SERVICE_ROLE_KEY="eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ..."

  ✅ Selesai!
