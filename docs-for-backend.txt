====================================================================
        RANCANGAN SISTEM BACKEND PORTFOLIO - PRISMA EDITION (V4)
====================================================================
Nama Proyek   : Decoupled Portfolio Content Management System
Pola Arsitektur: MVC (Model-View-Controller) + Prisma ORM
Status Konfig : Pre-configured (Environment Variable Ready)

--------------------------------------------------------------------
1. SKEMA DATABASE (Prisma Model)
--------------------------------------------------------------------
Lokasi File: `prisma/schema.prisma`

model Project {
  id           String   @id @default(uuid())
  title        String
  description  String
  tech_stack   String   // Disimpan sebagai string, contoh: "React, Node, PostgreSQL"
  image_url    String   // URL Publik dari Supabase Storage
  live_link    String?  // Optional
  github_link  String?  // Optional
  createdAt    DateTime @default(now())
  updatedAt    DateTime @updatedAt
}

--------------------------------------------------------------------

--------------------------------------------------------------------
/backend

--------------------------------------------------------------------
3. LOGIKA VALIDASI & KEAMANAN
--------------------------------------------------------------------
A. Validasi Data Kosong (Strict):
   Di `projectController.js`, sistem akan mengecek:
   - Jika `title`, `description`, atau `image_url` kosong/undefined, 
     backend akan mengembalikan status 400 (Bad Request).
   - Ini mencegah tampilan card kosong di Frontend React.

B. JWT Security:
   - Login menggunakan password statis yang ada di `.env`.
   - Hanya user dengan Token valid yang bisa menambah/menghapus proyek.

--------------------------------------------------------------------
4. KONFIGURASI SUPABASE (DI ISI TERAKHIR)
--------------------------------------------------------------------
Isi file `.env` di bawah ini harus Anda ganti dengan Key yang Anda ambil 
dari Dashboard Supabase:

DATABASE_URL="GANTI_DENGAN_CONNECTION_STRING_NODEJS"
DIRECT_URL="GANTI_DENGAN_CONNECTION_STRING_TRANSACTION_MODE"
SUPABASE_URL="GANTI_DENGAN_PROJECT_URL"
SUPABASE_SERVICE_ROLE_KEY="GANTI_DENGAN_SERVICE_ROLE_SECRET_KEY"
JWT_SECRET="ISI_DENGAN_KODE_ACAK_BEBAS"
ADMIN_PASSWORD="PASSWORD_LOGIN_DASHBOARD_ADMIN"
PORT=5000

--------------------------------------------------------------------
5. CARA MENGHUBUNGKAN (SETELAH KODE DIBUAT)
--------------------------------------------------------------------
Instruksi untuk Julian (Jalankan di Terminal Backend):
1.  `npm install` (Untuk install semua library)
2.  `npx prisma db push` 
    (Perintah ini akan otomatis membuat tabel di Supabase berdasarkan schema.prisma)
3.  `node server.js`
